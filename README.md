# Local LLM Chatbot

A simple AI chatbot built with Python, Streamlit, and Ollama.
The chatbot runs a local Qwen model and provides an interactive chat interface.

## Features

- Interactive chat interface
- Local LLM inference using Ollama
- Qwen 0.5B model
- Conversation history using Streamlit session state
- Simple and lightweight architecture

## Technologies

- Python
- Streamlit
- Ollama
- Qwen
- Requests
